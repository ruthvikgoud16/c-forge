# Notes and mind-map standard

## Notes

A topic notes object may include: introduction, beginner explanation, formal definition, terminology, syntax, diagrams, worked examples, steps, common mistakes, comparisons, applications, revision bullets, examination-ready answer.

Notes must use the official `sourceLabel` for academic mapping and may add accurate clarifications beside it.

## Mind maps

Mind maps are generated from catalog topics (`mindMapForUnit`). They are lists of labelled, linkable nodes with classification — not decorative images.

Unit 1 first-lesson map also includes the next official topics so a student can see what comes after binary and the block diagram.
